## 案例一｜围术期抽血：12步和500英尺如何暴露部门断点

> **出处**：Ch.5，PDF p.117–120；Table 5.1 / 5.2。

| 要素 | 内容 |
|---|---|
| 背景 | 同一类抽错手臂事件在**2周**内再次发生；经理Mike正在参加连续**5天、每天2小时**的工作方法课程。 |
| 做法 | 用[[术语/工作方法]]把当前方法拆为**12步**，逐项追问为什么、什么、哪里、何时、谁和怎样，再进行消除、合并、重排和简化。 |
| 数据成果 | 发现实验室人员需移动**200+50+250=500英尺**；拟议方法改为**7步**，末段运输约**20英尺**，并避免再次穿刺。原书未给百分比成果，本页不推算。 |
| 启示 | [[术语/工作分解表]]把“实验室没按规定做”改写成系统问题；部门之间也需要[[术语/方针管理]]式往返确认。 |

### 故事版

Mike第一反应是打电话责怪实验室。可他正在学工作方法，于是先把流程原样写出来：医嘱进入电子病历，实验室接单、打印标签、走到术前区、查白板、再去留观区、核对、抽血、贴标、走回实验室。数字把情绪变成事实——500英尺往返、一次重复穿刺，以及3年前为保险而留下的系统默认。护士提出把打印机放在留观区，在开始静脉输注时同步抽血，再用既有气动管道运输。实验室主管没有抵触，反而高兴技术员不必再中断巡回。真正改变关系的，不是一句“加强协同”，而是把共同工作摊开。

## 案例二｜模拟制造线：五轮实验才找到真正障碍

> **出处**：Ch.6，PDF p.136–141；原书明确写为 hypothetical example，案例性质为 simulation。

| 要素 | 内容 |
|---|---|
| 背景 | 模拟小工厂挑战为**1年**内生产率提高**50%**；月底目标为日产稳定在标准的**95%以上**，现状在**80%—105%**波动。 |
| 做法 | 依次用[[术语/工作指导]]训练**45秒**节拍、用[[术语/工作关系]]听取操作者意见、用[[术语/工作方法]]设计夹具与重排，再重新训练。 |
| 数据成果 | 经**5轮**PDSA，最终新方法维持节拍并连续运行**6小时**至班末。因为是教学模拟，不登记为真实企业绩效。 |
| 启示 | [[术语/改善套路]]的价值是改变问题定义；不能把“没守标准”直接归因于态度。 |

### 故事版

第一轮实验失败时，学习者以为操作员不会做；工作指导做过后仍失败，她又怀疑对方不愿做。工作关系让操作员终于说出真实情况：工具太重、空间太窄，他担心抱怨会丢掉喜欢的工作。第三轮才转向方法，团队设计夹具、调整顺序，第四和第五轮重新拆解并训练。五轮实验把问题从“人的态度”移到“方法与环境”。这是一段极好的教学故事，但原书已明说是假设例，不能对外写成某厂真实转型。

## 案例三｜大型医院急诊：从172.75分钟到141分钟

> **出处**：Ch.6，PDF p.141–153；Figures 6.8 / 6.9。

| 要素 | 内容 |
|---|---|
| 背景 | 上一财年出院患者停留时间**172.75分钟**，未就诊离院率**24%**，进门到服务者**54分钟**，普通X光**27分钟**、CT **57分钟**。 |
| 做法 | 用[[术语/工作方法]]设计2人分诊；用[[术语/工作指导]]分别训练记录者与执行者；压力下方法瓦解后，用[[术语/工作关系]]听意见并设置暂停阈值。 |
| 数据成果 | **4个月**内停留时间减少**50分钟**；**6个月**后稳定在**141分钟**，未就诊离院率**1.19%**，进门到服务者从**54降至33分钟**。 |
| 启示 | [[术语/改善套路]]把多次失败保留为学习，三种TWI技能必须按障碍组合。 |

### 故事版

团队最初以为把一位分诊护士改成两位就能提速：一人问诊录入，一人同步采血送检。现实很快打脸。排队一长，护士本能回到单兵救火，双人方法散掉。团队没有发通知强制执行，而是听取“这样会失控”的担忧，约定队列达到阈值时可以暂时退出新方法。这个安全边界让护士愿意继续练，周末班组后来反而被同事批评“没有按新流程”。结果改善发生在信任、方法、训练和实验同时到位之后。

## 案例四｜定制窗制造商：培训从160小时缩到60小时以内

> **出处**：Ch.6，PDF p.153–154；Training Timetable段。

| 要素 | 内容 |
|---|---|
| 背景 | 某定制窗制造商过去让新人跟着老员工“看着学”，约需**160小时**才能上手，主管仍不完全确定其掌握。 |
| 做法 | 用[[术语/工作指导]]拆解作业并按步骤训练，再把初训、首次验证和后续复核放进[[术语/培训时间表]]。 |
| 数据成果 | 不到**60小时**，主管已**100%**确认学习者掌握；作者同时记录许多组织最高观察到**75%**训练时间减少。 |
| 启示 | [[术语/标准作业]]只有与验证日期和技能等级相连，才能从文档变成组织能力。 |

### 故事版

传统带教把学习责任交给新人：站在熟练工旁边，多看、多问，时间到了就默认会了。工作指导反过来要求主管负责：先把重要步骤、关键点和理由讲清，示范，再让学习者做、说、教回来，最后按计划跟进。制造商得到的不只是缩短100小时以上，而是主管能明确回答“为什么确信他会了”。这正是培训时间表必须记录验证而不只记录上课日期的原因。
